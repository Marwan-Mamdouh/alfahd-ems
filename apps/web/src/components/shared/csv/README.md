# CSV Validation, Dropzone & Outcome Summary

This directory contains the client-side pre-validation and presentation components for bulk CSV file operations (specifically IP address import in Feature F6).

---

## Technical Specifications & Backend Parser Contract

The client-side validator (`csv-validator.ts`) enforces the exact constraints defined by the backend NestJS Multer upload and BullMQ import workers:

| Rule | Constraint | Details |
| :--- | :--- | :--- |
| **File Size** | Max 5 MiB (`5 * 1024 * 1024` bytes) | Enforced by backend Multer file size limit. Files exceeding this are rejected on the client before network upload. |
| **Row Count** | Max 5,000 nonblank rows | Large datasets are bounded to guarantee fast background job completion. |
| **Encoding** | UTF-8 with BOM support | Automatically strips the UTF-8 Byte Order Mark (`\uFEFF`) generated by Microsoft Excel on Windows. |
| **Required Headers** | `address` | Must be present as a column header in row 1. Case-insensitive comparison is performed. |
| **Optional Headers** | `notes` | Supported by backend IP import worker. |
| **Parser Limitations** | No multiline quoted fields | The backend fast-stream parser does not support multi-line quoted fields. The client validator detects unclosed quotes across lines and reports the exact line number. |

## Components & Utilities

### 1. `validateCsvFile(file, options)`

A pure async function that inspects the file header and structure prior to upload.

```typescript
import { validateCsvFile } from "@/components/shared/csv/csv-validator";

const result = await validateCsvFile(file, {
  requiredHeaders: ["address"],
  maxSizeBytes: 5 * 1024 * 1024,
  maxRows: 5000,
});

if (!result.isValid) {
  console.error("Validation error:", result.error);
} else {
  console.log("Estimated rows:", result.estimatedRowCount);
  console.log("Detected headers:", result.headers);
}
```

### 2. `<CsvDropzone />`

An accessible drag-and-drop file upload zone with integrated validation, keyboard navigation, and file removal.

#### Props

```typescript
export interface CsvDropzoneProps {
  /** Callback invoked when a validated file is selected or cleared */
  onFileSelect: (file: File | null) => void;
  /** Currently selected file */
  selectedFile: File | null;
  /** Custom required headers (defaults to ['address']) */
  requiredHeaders?: string[];
  /** Custom max size in bytes (defaults to 5MB) */
  maxSizeBytes?: number;
  /** Disable the dropzone interaction */
  disabled?: boolean;
  /** Custom helper subtext under the drop area */
  helperText?: string;
  /** Extra Tailwind classes */
  className?: string;
}
```

#### Example

```tsx
import { useState } from "react";
import { CsvDropzone } from "@/components/shared/csv/csv-dropzone";

export function FilePicker() {
  const [file, setFile] = useState<File | null>(null);

  return (
    <CsvDropzone
      selectedFile={file}
      onFileSelect={setFile}
      requiredHeaders={["address"]}
      helperText="Upload a .csv file with address and notes columns"
    />
  );
}
```

### 3. `<ImportSummary />`

Renders clean metrics cards and an expandable error breakdown table for completed import jobs.

#### Props

```typescript
export interface ImportErrorRow {
  row: number;
  address: string;
  reason: string;
}

export interface ImportSummaryProps {
  /** Count of successfully imported records */
  inserted?: number;
  /** Count of skipped duplicate records */
  skipped?: number;
  /** Array of line-numbered failed rows with reasons */
  errors?: ImportErrorRow[];
  /** Extra Tailwind classes */
  className?: string;
}
```

#### Example

```tsx
import { ImportSummary } from "@/components/shared/csv/import-summary";

export function JobResultView({ job }: { job: JobStatusResponseDto }) {
  return (
    <ImportSummary
      inserted={job.inserted}
      skipped={job.skipped}
      errors={job.errors}
    />
  );
}
```
